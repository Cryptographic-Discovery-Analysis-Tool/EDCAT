- **Why vendored:** SP 800-57's ECC column is by field size `f`; Curve25519's
  field is 255 bits, which that table alone would put at 112. This document
  states the recommended curves' strength directly, and that is what is used.

## Table 1 — Approximate Security Strength of the Recommended Curves (PDF pp. 17–18)

| Security strength | Recommended curves |
|---|---|
| 112 | P-224, K-233, B-233 |
| 128 | P-256, W-25519, Curve25519, Edwards25519, K-283, B-283 |
| 192 | P-384, K-409, B-409 |
| 224 | W-448, Curve448, Edwards448, E448 |
| 256 | P-521, K-571, B-571 |

Surrounding text: "The security strength of an elliptic curve is directly related
to the order of the basepoint."
